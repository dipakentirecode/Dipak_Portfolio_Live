# Dipak-Portfolio

Dipak Kumar Bharti's responsive, single-page portfolio built with React, TypeScript, Vite, and Tailwind CSS.

Profile copy, navigation labels, skill categories, project entries and statuses, social profile URLs, contact email, and resume path are centralized in `src/data/site.ts`. External links and the resume action appear only when their URLs are configured; no resume file, email, or social URLs are included by default.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```
